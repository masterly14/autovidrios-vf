## Variables de entorno requeridas

### Cloudinary (subida de PDFs)

- `CLOUDINARY_CLOUD_NAME`
- `CLOUDINARY_API_KEY`
- `CLOUDINARY_API_SECRET`

### WhatsApp Cloud API (envío de plantilla `factura_electronica`)

- `WHATSAPP_TOKEN`
- `WHATSAPP_PHONE_NUMBER_ID`
- **Opcional**: `WHATSAPP_API_VERSION` (por defecto `v20.0`)

### Resend (correo)

- **Opcional**: `RESEND_FROM_EMAIL` (por defecto `Autovidrios V&F <noreply@autovidriosvf.com>`)
